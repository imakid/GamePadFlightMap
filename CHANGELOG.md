# Changelog

## v1.3.0

### New Features / 新功能

- **Smart sorting** — Flight points are now sorted by: Reachable → Most-used → Nearest → Alphabetical  
  智能排序：可达优先 → 使用频率高优先 → 距离近优先 → 字母序
- **Flight frequency tracking** — Each flight destination's usage count is recorded and displayed in the list  
  飞行频率追踪：记录每个飞行目的地的使用次数并显示在列表中
- **New slash commands**: `/gpfm stats` (view statistics), `/gpfm resetstats` (reset statistics)  
  新增斜杠命令：`/gpfm stats`（查看统计）、`/gpfm resetstats`（重置统计）

### Notes / 备注

- Favorites feature code is preserved but disabled; can be re-enabled in future versions  
  收藏功能代码已保留但禁用，可在未来版本重新启用

## v1.2.0

- Initial release with bilingual README  
  初始发布，含中英双语 README

  可滚动的飞行点列表面板

- Click to highlight route, double-click to fly  
  单击高亮路线，双击飞行

- Gamepad D-pad navigation  
  手柄方向键导航

- Search filter  
  搜索过滤

- Toggle unreachable flight points  
  切换不可达飞行点显示
